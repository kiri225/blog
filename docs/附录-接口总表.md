开发时按阶段文档实现；本表用来对缺口和查参数。

## 认证 `/api/auth`

| 方法 | 路径 | 鉴权 | 参数 | 响应要点 |
|------|------|------|------|----------|
| POST | `/login` | 公开 | Body `{username, password}` | `{code, message, data:{accessToken, refreshToken, expires, avatar, username, nickname, roles, permissions}}` |
| GET | `/me` | 管理员 | | `{code, message, data:{avatar, username, nickname, email, description, phone, roles, permissions}}` |
| PUT | `/me` | 管理员 | Body 任意，认 nickname/email/bio\|description/avatar | `{code:0, message:"更新成功"}` |

错误：登录失败 401 `用户名或密码错误`；用户不存在 404。

## 文章 `/api/posts`

| 方法 | 路径 | 鉴权 | 参数 |
|------|------|------|------|
| GET | `/` | 公开 | Query `status?, category?(slug), tag?(slug), page=1, size=10 (le=200)` |
| GET | `/count` | 公开 | Query `status?` → `{count}` |
| GET | `/detail/{post_id}` | 公开 | 不增加 views |
| GET | `/{slug}` | 公开 | 增加 views |
| POST | `/` | 管理员 | Body PostCreate |
| PUT | `/{post_id}` | 管理员 | Body PostUpdate |
| POST | `/{post_id}/like` | 公开 | → `{likes}` |
| POST | `/{post_id}/unlike` | 公开 | likes 最小 0 |
| DELETE | `/{post_id}` | 管理员 | `{ok:true}` |

**PostCreate**：`title, slug` 必填；`description, content, cover, category_id, tags[], status=draft, is_pinned, reading_time, word_count`

**PostOut**：无 content；`category` 为分类名；`tags` 为名字列表

**PostDetail**：Out + `content`

## Schema 速查（必填）

| Schema | 必填字段 |
|--------|---------|
| LoginRequest | username, password |
| PostCreate | title, slug |
| CategoryCreate | name, slug |
| TagCreate | name, slug |
| CommentCreate | post_id, content |
| MessageCreate | content |
| ChatterCreate | content |
| ChatterCommentCreate | chatter_id, content |
| AlbumCreate | title |
| PhotoCreate | album_id, url |
| ProjectCreate | name, slug |
| FriendLinkCreate | name, url |
| SiteConfigUpdate | value |
| BookmarkCategoryCreate | name |
| BookmarkSiteCreate | category_id, name, url |

---

## 状态机

```
文章     draft → published → archived
说说     draft → published
评论类   pending / approved / rejected   （对照新建默认 approved）
项目     developing / active / archived
友链     is_approved false → true
```
