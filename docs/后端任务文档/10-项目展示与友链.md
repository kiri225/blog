## 项目接口

前缀：`/api/projects`，tag：`项目`

| 方法 | 路径 | 鉴权 | 说明 |
|------|------|------|------|
| GET | `/api/projects` | 无 | 列表，按 sort |
| GET | `/api/projects/{slug}` | 无 | 按 slug，404 `项目不存在` |
| POST | `/api/projects` | 管理员 | |
| PUT | `/api/projects/{project_id}` | 管理员 | 注意：更新用 **id**，详情用 **slug** |
| DELETE | `/api/projects/{project_id}` | 管理员 | |

### ProjectCreate

| 字段 | 类型 | 默认 |
|------|------|------|
| name | str | 必填 |
| slug | str | 必填，唯一 |
| description | str | `""` |
| long_description | str | `""` Markdown |
| cover_image | str | `""` |
| tech_stack | list[str] | `[]` |
| link_github / link_gitee / link_live / link_docs | str | `""` |
| status | str | `"developing"` |
| status_label | str | `""` 展示用文案，如「维护中」 |
| is_featured | bool | `false` |
| sort | int | `0` |

`status` 取值：`developing` / `active` / `archived`

### ProjectOut

与 Create 相同字段 + `id` + `created_at`（对照 Out 没有 updated_at，有也可以）

`tech_stack` 序列化同说说的 images。

## 友链接口

前缀：`/api/friend-links`，tag：`友链`

注意路径是 **`friend-links`**（连字符），不是 `friend_links`。

| 方法 | 路径 | 鉴权 | 说明 |
|------|------|------|------|
| GET | `/api/friend-links` | 无 | **仅已审核**，按 sort |
| GET | `/api/friend-links/admin` | 管理员 | 全部 |
| POST | `/api/friend-links` | 管理员 | 创建，默认 `is_approved=false` |
| PUT | `/api/friend-links/{link_id}` | 管理员 | 可改 is_approved |
| DELETE | `/api/friend-links/{link_id}` | 管理员 | |

`/admin` 必须写在如果以后加 `/{id}` GET 之前。现在 GET 动态段没有裸 id，但 PUT/DELETE 是 int，`admin` 不会冲突。仍把 `/admin` 放上面。

### FriendLinkCreate

`name, url` 必填；`avatar, description, sort=0`

**不含** `is_approved`。新建默认 False，前台看不到，直到管理员 PUT `{"is_approved": true}`。

### FriendLinkUpdate

以上 + `is_approved: bool | None`

### FriendLinkOut

`id, name, url, avatar, description, sort, is_approved, created_at, updated_at?`

## 验收标准

1. 创建项目 slug=`kirameku`，`GET /api/projects/kirameku` 能取到，`tech_stack` 是数组
2. 不存在的 slug → 404
3. 新建友链，前台 GET 为空（或没有这一条）
4. 管理员 `/admin` 看得到；PUT 审核后前台出现
5. 列表按 sort 升序
6. 无 Token 不能 POST

---

## 易错点

- 项目「读用 slug、写用 id」，和文章一样。不要做成 PUT `/{slug}`，除非你有意改规格。
- 友链 URL 前缀是 `friend-links`，前端也按这个拼。改成下划线会对不齐对照前端。
- `is_approved` 默认 False。若 Create 里手滑设成 True，前台会未审核就展示。
