## 相册接口

前缀：`/api/albums`，tag：`相册`

| 方法 | 路径 | 鉴权 | 说明 |
|------|------|------|------|
| GET | `/api/albums` | 无 | 按 sort 升序 |
| GET | `/api/albums/{album_id}` | 无 | |
| GET | `/api/albums/{album_id}/photos` | 无 | 按 sort |
| POST | `/api/albums` | 管理员 | |
| PUT | `/api/albums/{album_id}` | 管理员 | |
| DELETE | `/api/albums/{album_id}` | 管理员 | 建议同时删照片 |
| POST | `/api/albums/photos` | 管理员 | 添加一张照片（URL 已上传） |
| DELETE | `/api/albums/photos/{photo_id}` | 管理员 | |

`/photos` 写在 `/{album_id}` 之后时，`photos` 不是 int，不会误匹配。仍建议把 `POST /photos` 当作独立路径（对照就是 `/api/albums/photos`）。

### AlbumCreate

`title: str`，`description=""`，`cover=""`，`sort=0`

### AlbumOut

`id, title, description, cover, photo_count, sort, created_at, updated_at`

### PhotoCreate

| 字段 | 类型 | 默认 |
|------|------|------|
| album_id | int | 必填 |
| url | str | 必填（上传接口返回的 url） |
| caption | str | `""` |
| orientation | str | `"landscape"` |
| sort | int | `0` |

### PhotoOut

`id, album_id, url, caption, orientation, sort, created_at`

`orientation`：`landscape` 或 `portrait`

删相册：对照 SQL 是 `ON DELETE CASCADE`。`create_all` 可能不会级联，删除前先删该相册下所有 Photo，或手动写。

## 上传接口

前缀：`/api/upload`，tag：`上传`

### POST `/api/upload/image`

鉴权：**管理员**

Content-Type：`multipart/form-data`，字段名 **`file`**

规则（对照）：

| 项 | 值 |
|------|------|
| 允许类型 | jpeg / png / webp / gif / svg+xml |
| 最大体积 | 10MB |
| 类型不对 | 400 `不支持的文件类型: ...` |
| 过大 | 400 `文件大小不能超过 10MB` |

成功：

```json
{ "url": "https://cdn.example.com/kirameku/uuid.webp", "orientation": "landscape" }
```

宽 >= 高 → `landscape`，否则 `portrait`。Pillow 读失败时默认 landscape。

文件名：`uuid.hex + 原扩展名`。

## 学习阶段：本地存储（推荐先做这个）

不必配 OSS。流程：

1. 校验类型和大小（同上）
2. 写入 `uploads/{filename}`
3. 返回 `url = f"/uploads/{filename}"`（或拼 `http://localhost:8000/uploads/...`）
4. 阶段 01 的 StaticFiles 已经能访问这个 URL

之后要对齐生产，再把写入换成 `oss2.Bucket.put_object`：

- key：`{OSS_PREFIX}{filename}`
- 返回 url：`{OSS_CUSTOM_DOMAIN}/{oss_key}`

环境变量见 [00-约定与架构.md](./00-约定与架构.md)。

## 验收标准

1. 创建相册，列表按 sort 排序
2. 先 upload 拿到 url，再 POST `/photos`，相册 `photo_count` 变为 1
3. GET `/{id}/photos` 看得到该照片
4. 删照片后 `photo_count` 变 0
5. 无 Token 上传 → 失败
6. 上传 `.txt` → 400
7. 本地模式下浏览器能打开返回的 url 看到图片

---

## 易错点

- 上传不是 JSON。Swagger 里应出现文件选择框；若你用了 Pydantic 当参数，会变成 JSON Body。必须 `file: UploadFile = File(...)`。
- 需要依赖 `python-multipart`，否则 multipart 解析报错。
- 相册封面 `cover` 和照片 `url` 都只是字符串，上传是独立接口，相册接口不接收文件。
- svg 用 Pillow 读尺寸可能失败，走默认 landscape 即可。
