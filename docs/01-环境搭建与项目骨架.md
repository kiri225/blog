## 要做的文件



### 1. `app/config.py`

- `BASE_DIR` 指向项目根（`app/` 的上一级）
- `load_dotenv(BASE_DIR / ".env", override=True)`
- 至少导出：`DATABASE_URL`、`SECRET_KEY`、`ALGORITHM="HS256"`、`ACCESS_TOKEN_EXPIRE_HOURS=72`、`CORS_ORIGINS`（逗号拆成 list）



### 2. `app/main.py`

对照行为：

```python
app = FastAPI(title="Kirameku Backend", version="1.0.0", lifespan=lifespan)
```

`lifespan` 里现在可以只 `yield`；阶段 02 再调用 `init_db()`。

必须有的两段：

- `app.add_middleware(CORSMiddleware, allow_origins=CORS_ORIGINS, allow_credentials=True, allow_methods=["*"], allow_headers=["*"])`
- `app.include_router(api_router)`

静态目录：项目根下创建 `uploads/`，挂到 `/uploads`。目录不存在就 `mkdir`。

### 3. 两个基础接口（写在 `main.py`）


| 方法  | 路径            | 鉴权  | 响应                                              |
| --- | ------------- | --- | ----------------------------------------------- |
| GET | `/api/health` | 无   | `{"status": "ok"}`                              |
| GET | `/api/routes` | 无   | `{"code": 0, "message": "success", "data": []}` |


`/api/routes` 是管理后台菜单占位，返回空数组即可。

### 4. `app/api/router.py`

```python
from fastapi import APIRouter

api_router = APIRouter()
# 后续阶段：api_router.include_router(xxx_router)
```

`app/api/__init__.py`：`from app.api.router import api_router`

## 启动

```powershell
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

或写一个 `start.py`（对照 `start.py`）：`uvicorn.run("app.main:app", host="0.0.0.0", port=8000, reload=True)`

---



## 验收标准

1. `GET http://localhost:8000/api/health` 返回 `{"status":"ok"}`
2. `http://localhost:8000/docs` 能打开 Swagger，能看到 health
3. 改 `main.py` 后 `--reload` 会自动重启
4. `.env` 里的 `SECRET_KEY` 能在 `config` 里读到（可临时 print 验证，验证完删掉）

---



## 易错点

- 启动模块路径是 `app.main:app`，要在**项目根**执行，不要进到 `app/` 里再启动。
- `CORS_ORIGINS` 是用逗号 split 的字符串，注意不要多空格，或 split 后 `.strip()`。
- `python-dotenv` 对照项目的 `requirements.txt` 里没写，但 `config.py` 用了，练习项目请显式写上。
